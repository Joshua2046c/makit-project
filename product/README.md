# T5 Pocket 单词机

采用用户指定的 Tuya T5AI Pocket（索引 tuya/t5ai-pocket）及原配屏幕、电池、摇杆。外壳参考新增两张图片：暖米杏色圆角机身，大面积黑色屏幕面板，下方暖色按键分区，以及橄榄绿主功能键。以真实硬件决定安装结构，保留左摇杆、右侧三个按键和左下两个按键。

## 硬件与证据

主板约116.2×67.3×1.2mm。显示器为鱼鹰光电 YDP290H001-V3，2.9英寸168×384全反射单色LCD、ST7305驱动；参考图中的大尺寸彩屏不属于本方案。电池采用原配Nintendo HAC-006、3.7V 525mAh。机械依据为官方Rev-C装配STEP、原厂图纸及用户照片：https://oshwhub.com/tuyaopen/graffiti-t5pocket-pocket-machine 。淘宝页面未提供可读套餐详情，购买时按实际已含附件核对，不重复购买。

## 造型和结构

平面尺寸134×88mm，侧面为约8°楔形，上沿USB一侧厚、下沿操控区薄，暖色壳体边缘名义厚度17.2–29.57mm，黑色面板另高1mm；整体几何包络约134×88×30.48mm，不含外露操控件。保持原主板、LCD、麦克风和按键对位，通过背壳向背面增厚形成斜坡；外周倒角、圆角。米杏色壳体保留黑色完整功能面板，橄榄绿主键，配色沿用既有方案。正面与侧面设置错落芝士圆形盲凹，避开功能孔、安装柱和镜片；左下前壳圆角边缘增加直径8mm、深1mm的球面盲凹，与既有装饰一致。底面恢复八处完整球面圆凹和三处跨边缘凹洞，沿用原来的直径、深度和排布。相邻两侧圆凹重排孔位，由R18mm圆弧通道贯通，孔口向内收圆滑过渡。通孔直径4mm，孔口过渡R0.5；为绕开该角螺钉，局部工具井默认直径5.5mm，原螺钉和承压座保留。

USB-C、顶部10针扩展口及左侧TF卡口的内凹槽只从侧壁进入；正面及黑色面板外周连续，没有向正面敞开的接口缺口。局部保留顶盖，开口缩紧，上下圆角对称，平台向内延伸，减少接口下方的电路板暴露和无用空位。中间功能键为6.6mm圆帽与7.2mm圆孔。屏幕开窗70.5×30.5mm，四边缩进1mm以增加圆键侧留白；透明镜片仍为77×39×1mm，隐藏在面板下方。

前后壳从背面四颗沉头螺钉闭合。楔形背面保留螺丝刀进入井，原螺钉头落在平面承压座中。主板四柱定位；电池独立限位槽使用可移除泡棉胶，留板背线缆空间；摇杆由托台、软垫和独立压框固定。LCD使用3mm C形支架，1mm亚克力镜片由前壳台阶承担载荷。双麦克风各自独立声道，扬声器经三条狭槽出声。前后壳及功能面板默认PETG，声学圈与缓冲垫使用软TPU。摄像头与Pogo附件不配置。

独立挂环参考用户上传key-ring.3mf的扁平环、错位搭接舌片结构，自主参数化适配现有R18、直径4mm孔道；橄榄绿色、默认SLS无填充PA11尼龙。环身截面3.2×2.6mm、外径39.2mm、内径32.8mm，舌片搭接间隙0.4mm，内侧止退凸舌卡入外侧凹位。向内拨动舌端解除止退，错开两端后逐段穿入孔道，再复位扣合；展示时独立放在机壳旁边。实际穿入、释放力和耐久需首件试装。

## 验收

交付独立零件的STEP模型和装配说明，检查刚性件干涉、打印体连接、螺钉长度、按钮运动和端口插入净空。有意的轴孔压配、柔性连接器插接及密封圈压缩应单独标注，不把其他干涉隐藏为过盈。实物打印收缩、声学、按键手感及充电插拔仍需样件验证；不交付固件或新增PCB。
