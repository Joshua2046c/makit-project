# 暖米杏色 T5 Pocket 单词机外壳

## 用途和造型
掌上阅读及语音学习，桌面使用时前面板相对底面倾斜8°。主体为上沿USB侧厚、下沿操控侧薄的圆角楔形，带盲凹洞的玩具式芝士外观；平面134×88mm，暖色壳体边缘名义厚度17.2–29.57mm；含面板的整体几何包络约134×88×30.48mm，含外露操控件约134×89.41×35.41mm。正面黑色屏幕功能面板连续，接口内凹槽只从侧面进入。米杏色壳体、黑色面板、橄榄绿功能键配色沿用既有方案。
正面操控带及侧壁保留非网格芝士盲凹；底面八处完整球面凹坑及三处底部跨边缘凹洞恢复。侧面接口采用较小、上下R角对称的圆角开口与向内延伸的凹台。相邻+X/+Y侧面标出的两处圆凹以弧形通道贯通，孔口R0.5向内收圆滑过渡；孔径4mm。玻璃、屏幕窗口、按键、声孔、接口和螺柱周围留净区。轮廓圆角与边缘倒角贯穿楔形。
+Z正面、-Z背面、+Y上沿、-X为TF侧。内部硬件基准保留，通过后壳向背面延伸形成楔形；背面工具进入井保留原沉头螺钉平面承压座。
 
## 来源及接口
真实主板、LCD、HAC-006电池和摇杆来自官方Rev-C STEP，未以包络盒替代。来源：https://oshwhub.com/tuyaopen/graffiti-t5pocket-pocket-machine 。主板约116.2×67.3×1.2mm；屏幕是YDP290H001-V3、2.9英寸168×384 ST7305全反射单色LCD，不是参考照片中的大彩屏。前后壳、镜片安装、压框、电池槽及电源键为自主设计。原厂外壳和压板已移除。
接口ID：screen_and_board_mounting, battery_compartment, usb_c_charge, speaker_aperture, dual_microphone_apertures, snap_ring_mount。参考ID：tuya_mechanical, reference_images, key_ring_3mf_reference。摄像头和Pogo磁吸扩展未配置，不增加相应孔、压板或磁铁。顶部10针扩展口保留。

## 结构布局
机身正面与背面主平面夹角8°，高低差12.3676mm，上沿USB侧厚、下沿操控侧薄。后壳向背面增厚，不移动原主板、LCD、按键及声学组件。主轮廓R9，前外沿R1，斜底周边0.6mm倒角；前后接缝0.35mm、定位唇每侧0.3mm滑动间隙。壳体侧壁2.4mm、前皮2mm；背壳内底仍使用原Z基准，楔形增厚部分由切片填充比例控制。
四处M2.5×6沉头闭合连接保留原平面承压座。弧形通孔所在角的螺丝刀进入井缩为5.5mm，其余三处仍为8mm；原沉头孔座开口5.1100mm、螺钉头直径4.3818mm，均保留。从背面可用细杆螺丝刀经工具进入井触及原沉头螺钉，不在8°斜面上斜压螺钉头。主板四柱以M2.5×5固定，摇杆压框两颗M2×6。
电池相对原配位置向后下沉4.1mm、向上移1.8mm。电芯51×24.2×5.5mm，槽每侧0.5mm间隙，底部0.5mm可移除泡棉胶，板背导线从左侧缺口布置，不夹线或压电芯。摇杆下沉1.1mm，上方独立压框、两片0.4mm自由高度TPU耳垫与底部承台固定；耳垫压缩至约0.3mm。
LCD使用3mm C形支架，右开口避让原FPC座；77×39×1mm亚克力镜片在台阶内定位，玻璃与LCD约0.96mm间隙。黑色面板122×54×1mm，窗口70.5×30.5mm，外周连续。中间功能键6.6mm圆帽与7.2mm圆孔。窗口四边各缩进1mm，保持屏幕居中和原镜片座；圆帽外缘到窗口的投影间隔约2.04mm，按键孔与窗口之间最窄实体带约1.74mm。
USB-C、顶部排针及左侧TF口使用紧凑、上下镜像对称的圆角开口，不向正面开口。每口配约1.4mm围壁及底部平台，沿插入方向向内延伸，减少孔下方的板件暴露。接口外口/内喉口分别为：
- USB-C：16×7mm、R1.5；内喉口14×7mm、R1.5。中心X=41.9191、Z=-2.745，内沿Y=25.8mm，内部轴向再让开0.6mm。
- 扩展排针：29.5×5.2mm、R1.3；内喉口27.6×4.2mm、R1.0。中心X=-1.1341、Z=-6.9200，内沿Y=27.5mm。中心高度依据官方模型U14的Z=-8.1200..-5.7200mm。整圈围框归前壳，后壳接缝绕到围框下方，留0.3mm装配避让，避免接缝截断下方圆角。
- TF：20.5×8mm、R1.8；内喉口19.5×5.8mm、R1.5。中心Y=-21.0、Z=-3.9，内沿X=-59.7mm；与摇杆压框翼局部留0.3mm避让。
本节坐标为机身局部结构基准。世界姿态为整体Rx(8°)，再向Z平移22.5408937165mm；所有零件保持斜底贴平。
相邻+X侧(Y=16.1906,Z=-18.5)与+Y侧(X=47.8632,Z=-18.5)的圆凹连接成直径4mm的R18圆弧穿孔；与独立圆形卡环共用曲率，避开角部工具井。孔缘R0.5圆滑内收。以上为机身局部结构坐标。
底面沿原位置恢复八个完整球面凹坑，直径19、12、22、13、10、8、5、6mm，对应深度2.8、2.0、3.1、1.8、1.2、0.85、0.65、0.95mm；三处跨底面棱边凹洞位于局部平面坐标(-68.2,5)、(66,-15)、(-12,34.4)，直径12、9、8mm，深1.4、1.0、1.0mm。所有底面凹坑沿8°底面的法向切削。共45处圆凹外观，其中2处为弧形通道孔口、其余43处为盲凹：前壳及上侧壁18处、后壳侧壁11处、后壳底面及跨棱11处、黑色面板5处。凹洞直径3.8–22mm、深0.3–3.1mm，正面坑底局部余厚1.6mm。左下前壳圆角边缘增加直径8mm、深1mm球面盲凹，按45°角位置、相对平面轮廓半径内收1.2mm，局部内侧补足余厚；暖米杏色与既有芝士装饰相同。
双麦克风各2.4mm孔及独立TPU声道，右下扬声器三条1.4×7mm格栅、中央8mm声道保留。电源键由导向和肩部捕获，中性不预压。

## Making and assembly / 制作和装配
11件PETG结构件及键帽、1件亚克力镜片、5件软TPU密封圈/垫，加1件SLS PA11卡环，共18个制作件。底面采用球面盲凹及跨边缘凹洞；后壳仍以其保留的平底面贴平台。底面球面顶部需通过首件校准桥接和悬垂，任何支撑必须能从凹洞取出。硬壳区域默认0.2mm层高、0.4mm喷嘴、至少4层周壁；前壳可正面朝平台；后壳把8°斜底贴平平台，此时内部孔轴偏离平台法线8°，需随首件收缩校准。楔形增厚区可用15–20%填充起试，功能柱和周壁保留至少4层。按桥接效果为端口顶盖、内延平台及工具井局部加支撑；承压座不得留支撑残渣，可见大面不要接触支撑。软TPU建议85A，0.1mm层高，两个小耳位垫用细喷嘴或小裙边；这些是软垫，不承担螺纹或主要侧向载荷。TPU垫也可按相同尺寸使用成品软垫。
弧形通道内部不应填入无法取出的支撑；首件需清理孔口与内壁并用柔线试穿，未进行承载寿命测试。
1. 镜片落入前壳台阶，使用约0.1mm薄双面胶；黑色面板胶层约0.10–0.12mm。保持清晰窗口无胶。前壳台阶定位，不靠玻璃变形闭合。
2. 3mm C形支架底部用薄胶层约0.07mm，上部用0.5mm软泡棉胶压到约0.43mm；只贴有支承的边缘。镜片与LCD玻璃约0.96mm间隙。插接原配24P LCD排线，保留自由弯折段。
3. 电源推键从内侧放入导轨，肩部留在壳内；中性位置不预压开关。两只麦克风圈分别形成独立声道，扬声器环接到格栅背后；透声网不可用不透声胶膜代替。
4. 先装摇杆，再装软垫和压框，轻拧两颗M2×6。摇杆由托台承受按压，压框仅负责压持和抗拔。按原配极性和接口连接，不改电路。
5. 装主板，使用四颗M2.5×5。电池放入独立槽，0.5mm泡棉胶留拉出胶尾；整理板背导线，保留插头周围余量，不夹线、不挤压电芯。
6. 五只PETG键帽分别套在原开关轴上，2.98mm卡口为试样轻压配，需随打印收缩校准。中间键改为直径6.6mm圆帽，前壳和黑色面板均为7.2mm圆孔，单侧名义间隙0.3mm。
7. 前后壳沿定位唇合拢，从背面四处工具井拧入M2.5×6沉头螺钉闭合，螺钉头落在原平面承压座。三类螺钉不能混长使用；本款不沿用旧外壳M3×8或摇杆M1.6螺钉。

## 连接清单
四处壳体闭合、四处主板安装、两处压框安装均由打印螺接标准件方案生成，孔型、补偿、螺钉及长度由方案返回。实际标准分别为ISO7046 M2.5-0.45×6、ISO7045 M2.5-0.45×5、ISO7046 M2-0.4×6。后盖沉头承压余厚约1.295mm。镜片、面板、屏幕支承和电池为明确的胶接实现；电源键为导向滑动；五个键帽压配、五只软垫/密封圈压缩及两处原配FPC插接均在源中声明。

## 独立扁平搭接挂环
依据上传key-ring.3mf所示扁平环、错位搭接舌片和一体开口结构，独立编写参数化适配版。文件包含外径约34、30.6、27.4mm、厚4、3.6、3.2mm三种网格及照片；作者元数据Stenly_G、许可元数据BY-NC-ND，原文件作为参考保存，未把原三角网格导入制造件。
采用孔道已有R18环心半径，截面径向宽3.2mm、轴向厚2.6mm、截面圆角R0.65，外径39.2mm、内径32.8mm；橄榄绿、无填充PA11尼龙SLS。环身双面浅槽宽0.35mm、深0.25mm，与参考的扁平双沿外观一致。
接头为径向错位的内外两条弧形舌片，单条宽1.4mm，缝0.4mm，搭接37.6°；内舌的止退凸部扣入外舌凹位，止退量0.25mm，静态最小活动余量0.25mm，外侧保留约0.9mm径向材料。此结构由环体自身材料挠曲释放，连接清单中snap_ring_mount及integral_ring_snap为自主free实现，没有独立活动五金。挂环保持一个独立制作件，展示位置在机壳旁边。
向内轻拨内舌自由端使止退肩离开凹位，再把两端错开并逐段送入4mm圆弧孔，复位扣合。安装包含弹性变形，不能用完整闭环刚性平移代替。PA11首件需清理搭接缝并验证开合、穿入与循环寿命；未规定额定载荷。材料选择沿用既有PA11方案，依据：https://formlabs.com/products/nylon-11-powder/ 。
